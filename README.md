# salcode Neovim Configuration

## Setup

### 1. Make Backup of Existing files in `~/.config/nvim`

### 2. Remove Existing `~/.config/nvim`

```
rm -rf ~/.config/nvim
```

### 3. Clone repo

Clone repo, e.g.

```
git clone git@github.com:salcode/salcode-nvim.git ~/salcode-nvim
```

### Create Symlink

e.g.

```
ln -sf ~/salcode-nvim ~/.config/nvim
```
